# План / идеи

## 1. Управляемые ПТУРы с разными ГСН

Сейчас ПТУР наводится по лазерному лучу стрелка. Идея: добавить ракеты с собственными головками самонаведения (ГСН), у каждой свои сильные и слабые стороны.

> **Важно:** всё программное обеспечение ракеты (логика ГСН, захват, наведение, реакция на потерю цели) по-прежнему пишет **сам игрок**. Игра предоставляет только API: сенсоры ракеты и управление курсом. Готового «автопилота» в движке нет.

### 1.1 ПТУР с ИК-наведением (пассивный)

- Летит исключительно на тепло, выделяемое двигателями танка (по аналогии с ИК-ГСН).
- Наведение пассивное: ракета ничего не излучает, поэтому цель не получает СПО-предупреждение.
- Потеря захвата:
  - танк уехал за препятствие (стена или остов блокируют линию видимости);
  - сброшена дымовая завеса — ИК-головка теряет захват.
- Источник тепла зависит от работы двигателя (стоящий танк почти не светится, быстрый — ярче). Точные правила — обсудить.

### 1.2 ПТУР с активным лазерным наведением (по аналогии с АРЛ-ракетой)

- Ракета сама излучает лазерные импульсы (пучки) и ищет танк.
- Видит только то, что движется с угловой скоростью относительно ракеты.
- Танк, идущий в «нотче» (перпендикулярно линии визирования), теряет захват — по аналогии с доплеровским режимом лазера и константой `DOPPLER_NOTCH_DEG`.
- Активный режим излучает, значит цель может получить предупреждение (СПО).

### 1.3 Общее: API для игрока

Что нужно проработать:

- как игрок пишет код ракеты: класс-наследник (по аналогии с ботами, `bots/`), колбэки ракеты (старт, обновление сенсоров, потеря цели);
- что видит ракета: данные сенсора ГСН (угол, угловая скорость, яркость или дистанция — зависит от типа), без координат цели в обход ГСН;
- что может ракета: управление курсом с ограничением угловой скорости (`PTUR_MAX_TURN`), возможно, подрыв по команде;
- белый список методов и песочница по аналогии с `BOT_API_WHITELIST` и `makeBotProxy` — ракета не должна читать лишнее;
- как бот выбирает тип ракеты и подгружает свой код (формат выстрела, например `fire({ seeker: "ir", brain: MyMissile })`);
- баланс: скорость, дальность, боезапас, перезарядка каждого типа;
- настройки меню и подсказки для новых типов ракет.

## Заметки

- Для ИК-наведения нужна модель «тепловой заметности» танка и учёт препятствий и дыма на линии ракета–цель (у лазера это уже есть в `castLaser` и `segmentHitsWall`).
- Для АРЛ нужна оценка угловой скорости цели и нотча, механика уже есть в умном лазере (поколение II).
